# 局域网视频共享

一个面向 Windows 局域网使用的轻量视频共享工具。把指定目录通过 Web 服务共享出来，手机、平板或电脑打开局域网地址后，可以浏览视频、查看预览图、长按预览并直接播放。

## 功能

- 指定 Windows 目录作为共享目录。
- 递归扫描目录下的视频文件。
- 支持浏览器内直接播放视频，并支持拖动进度条。
- 手机端单屏布局：播放器固定，视频列表独立滚动。
- 视频列表懒加载缩略图。
- 长按视频卡片，从视频中段静音预览。
- 本机浏览器自动保存播放进度。
- 再次播放同一视频时自动续播。
- 播放超过 90% 或播放结束后标记为已看，并排到列表后面。
- 支持收藏和拉黑，数据保存在服务端本地 `data/preferences.json`，同一个局域网服务下多台设备共享。
- 收藏视频优先显示；拉黑视频默认隐藏，可通过“显示拉黑”临时查看和恢复。
- 切换视频不会重建列表，缩略图和滚动位置不会被重置。
- 单个“全屏播放”按钮会根据视频宽高尝试锁定横屏或竖屏。
- 可选 URL 访问口令。
- 支持 PWA，可添加到手机主屏幕以独立窗口打开。

## 环境要求

- Windows
- Node.js 18 或更新版本
- 手机和电脑需要连接同一个局域网 / Wi-Fi

## 启动

进入项目目录：

```powershell
cd "C:\Users\Link\Documents\局域网共享"
```

共享指定目录：

```powershell
npm start -- "E:\x"
```

指定端口：

```powershell
npm start -- "E:\x" --port 8080
```

启动后终端会输出类似：

```text
Local:   http://localhost:8080
Network: http://192.168.1.14:8080
```

手机打开 `Network` 地址即可访问。

## 可选访问口令

局域网自用可以不设置。需要简单限制访问时：

```powershell
$env:SHARE_TOKEN="123456"
npm start -- "E:\x"
```

访问地址：

```text
http://192.168.1.14:8080/?token=123456
```

## 支持格式

默认显示以下扩展名：

```text
.mp4 .m4v .mov .webm .mkv .avi .wmv .flv .ts .m3u8
```

iPhone Safari 对 `.mp4`、`.m4v`、`.mov` 支持最好。`.mkv`、`.avi` 等格式可能能显示在列表里，但浏览器未必能直接播放。

## 手机端使用方式

1. 点视频卡片开始播放。
2. 点“全屏播放”进入全屏观看。
3. 工具会根据视频实际宽高尝试锁定横屏或竖屏。
4. 长按视频卡片可以从中段静音预览。
5. 看过的视频会显示进度并自动排到后面。
6. 点卡片里的“收藏”可以把视频排到前面，所有客户端都会共享这份收藏状态。
7. 点卡片里的“拉黑”会把视频从默认列表隐藏，所有客户端都会共享这份拉黑状态。

注意：iPhone Safari 不允许网页稳定强制锁定屏幕方向，所以横竖屏锁定是 best-effort；如果系统拒绝锁定，需要手动旋转手机。

## 添加到主屏幕

PWA（Progressive Web App）可以让网页像 App 一样从手机主屏幕打开。

iPhone Safari：

1. 用 Safari 打开局域网地址。
2. 点底部分享按钮。
3. 选择“添加到主屏幕”。
4. 之后从主屏幕图标打开，通常会以独立窗口显示，减少浏览器地址栏干扰。

说明：PWA 的离线缓存只缓存页面壳、样式和脚本，不缓存视频文件和 `/api/videos` 列表，避免占用空间或额外留下视频副本。

## 安全和隐私

- 适合可信局域网内个人使用，不建议直接暴露到公网。
- 播放进度和已看状态仍保存在当前浏览器的 `localStorage` 中，避免不同设备互相影响观看进度。
- 收藏和拉黑状态保存在服务端本地 `data/preferences.json` 中，供同一个服务下的多台设备共享；`data/` 目录默认不提交到 Git。
- Windows 防火墙可能会询问是否允许 Node.js 通过网络，需要允许后其他设备才能访问。
